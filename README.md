# Developers protfolio

A Next.js project with TypeScript, App Router, Tailwind CSS, and ESLint.

## Getting started

Requires Node.js 20.9 or newer.

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Edit `src/app/page.tsx` to build the portfolio.

## Checks and production

```bash
npm run lint
npx tsc --noEmit
npm run build
npm start
```
